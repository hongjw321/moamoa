# MOAMOA v2 — 모아모아

승인된 모아모아 3D 홈페이지 시안의 실제 이미지 자산을 메인, 캐릭터, 상품, 이벤트 영역에 반영한 GitHub Pages용 프론트엔드 MVP입니다.

## 업로드
저장소 최상위(root)에 `index.html`, `styles.css`, `app.js`, `README.md`, `assets/` 폴더를 올립니다. `index.html`이 첫 화면에서 바로 보여야 합니다.

## GitHub Pages
저장소 Settings → Pages → Deploy from a branch → `main` → `/ (root)` → Save.
기존 Pages 설정이 이미 켜져 있다면 파일 업로드 후 자동으로 갱신됩니다.

## 포함 기능
- 반응형 홈페이지
- 무료 체험 뽑기 1회
- 캐릭터 도감 및 획득 여부
- 마이페이지 수집 현황과 뽑기 기록
- 샵/이벤트 소개 영역

## 현재 제한
이 프로젝트는 프론트엔드 데모입니다. 뽑기와 수집 기록은 브라우저 localStorage에 저장됩니다. 실제 회원별 동기화, 서버에서의 공정한 랜덤 추첨, 결제 및 주문/배송은 백엔드와 별도 연동이 필요합니다. 상품 가격은 디자인 예시이며 판매 기능은 활성화되어 있지 않습니다.

이미지 일부는 홈페이지 시안에서 잘라낸 시각 자산을 사용합니다. 캐릭터별 독립 원본 일러스트 및 상품별 최종 인쇄용 원본은 후속 디자인 단계에서 별도로 제작해야 합니다.
