# MOAMOA — 모아모아

GitHub Pages 기반의 캐릭터 수집 서비스 MVP입니다.

## 배포 주소
- https://hongjw321.github.io/moamoa/

## 현재 구현된 기능
- 반응형 메인 페이지 및 캐릭터/상품 소개
- 이메일 회원가입·로그인·인증 메일·비밀번호 재설정(Supabase Auth)
- 회원가입 프로필(이름·닉네임 필수, 휴대폰·주소 선택)
- 마이페이지 프로필 조회·수정
- Supabase `user_data` 테이블을 통한 회원별 기록 동기화
- 무료 체험 뽑기, 캐릭터 도감, 출석, 장바구니 미리보기
- 이용약관 및 개인정보 처리방침 초안 페이지

## 배포 및 설정
1. GitHub 저장소의 `main` 브랜치와 root를 GitHub Pages로 배포합니다.
2. Supabase 프로젝트의 URL과 publishable/anon key를 `supabase-config.js`에 설정합니다. 브라우저용 publishable key만 사용하고 service_role/secret key는 절대 커밋하지 않습니다.
3. `supabase-schema.sql`을 Supabase SQL Editor에서 실행해 `user_data` 테이블과 RLS 정책을 적용합니다.
4. Supabase Authentication의 Site URL 및 Redirect URL에 실제 배포 주소를 등록합니다.
5. SMTP를 설정한 경우 인증 메일 발송을 확인합니다.

## 현재 운영 제한 — 반드시 확인
이 저장소는 아직 상용 서비스 완성본이 아닙니다.
- 뽑기는 현재 브라우저 JavaScript에서 실행됩니다. 브라우저 저장정보 삭제·조작으로 제한을 우회할 수 있으므로 유료 뽑기, 보상, 현금성 재화와 연결하면 안 됩니다.
- 클라우드 동기화는 사용자 데이터 저장용 MVP입니다. 추첨 결과 검증, 거래 원장, 부정 이용 방지, 서버 권한 검증은 구현되지 않았습니다.
- 샵은 상품 미리보기와 장바구니 데모입니다. 결제, 주문 생성, 재고, 배송, 환불 기능이 없습니다.
- 회원 계정의 셀프 탈퇴/개인정보 삭제 기능은 아직 없습니다.
- `privacy.html`과 `terms.html`은 현재 기능에 맞춘 검토용 초안입니다. 대괄호의 운영자 정보·연락처·보유기간·시행일, Supabase 국외 이전 여부 등을 확정하고 법률 검토 후 사용해야 합니다.
- 사업자 정보, 고객센터, 실제 판매 상품·가격·배송·교환/환불 정책이 준비되기 전에는 상품 판매를 시작하지 않습니다.

## 개인정보 및 보안
- `supabase-config.js`의 publishable key는 브라우저 공개용입니다. secret/service_role key를 프론트엔드에 넣지 마세요.
- 회원별 `user_data`에는 RLS가 적용되어 있습니다. 정책 변경 시 반드시 본인 계정/다른 계정 접근 테스트를 수행하세요.
- 휴대폰 번호와 주소는 선택 항목이며, 실제 목적과 처리방침이 확정되기 전에는 수집하지 않는 것을 권장합니다.
